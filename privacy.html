プライバシーポリシー（jinsei-owari-upload）

最終更新日：2026年11月14日

使う情報

このアプリは、運営者本人が許可した YouTube アカウントについて、YouTube Data API を通して次の操作だけを行います：自分のチャンネルの確認、動画の投稿、公開予約の設定、サムネイルの設定、投稿した動画の状態の確認。

保存と共有

許可の情報（アクセストークン）は運営者本人のパソコンの中にだけ保存し、第三者に渡したり、販売したりしません。運営者以外の利用者の個人情報は集めません。

このアプリによる Google API から受け取った情報の利用は、Google API Services User Data Policy（限定的使用の要件を含む）に従います。

許可の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも許可を取り消せます。

問い合わせ

YouTube チャンネル「人生終わった話【漫画】」のコメント欄からお問い合わせください。
